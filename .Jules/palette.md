## 2024-11-01 - Improve CLI workflow status alignment and icons
**Learning:** Using simple tabular string formatting (`ljust()`) and emojis (✅/⏳/📄/📁) in CLI output significantly improves scannability and UX compared to jagged text lines with bracketed tags `[OK]`/`[WAIT]`.
**Action:** When designing CLI list outputs, prefer aligned columns and intuitive status icons to reduce cognitive load.
