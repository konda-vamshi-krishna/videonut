# VideoNut Aider conventions

You are coding inside the VideoNut repository. This codebase runs a multi-agent
AI pipeline (12 agents) that generates YouTube documentaries end to end,
including the voiceover.

## 🤖 Adopt VideoNut personas
If the developer asks you to perform a task acting as one of the specialized agents:
- Look up their behavioral guidelines and instruction sets inside `_video_nut/agents/`.
- Perform the requested narrative, research, audio or technical step exactly
  according to the agent's XML specifications and output file formats.

## 🏗️ Agents are compiled, not hand-written
`_video_nut/agents/**` is the source of truth. Everything at the repository root
(`.claude/`, `.gemini/`, `.qwen/`, `.opencode/`, `.hermes/`, `.codex/`) is
generated by `python _video_nut/scratch/generate_agents.py`. Never edit the
generated copies — edit the source and recompile.
`_video_nut/cli_templates/**` is NOT generated; update it by hand.

## 🔐 Secrets
API keys belong in `.env` (gitignored). `config.yaml` is committed, published to
npm and copied into every user project — never put a key there.

## 💸 Spend discipline
The Narrator (`_video_nut/tools/audio/`) is the only component that can spend
money. Any code path that can call a paid TTS API must print a character count
and cost estimate first, and must be skippable with `--dry-run`.

## ✅ Before you finish
```bash
python tests/run_tests.py          # 27 tests, no network, no spend
cd _video_nut && npm run verify-package
```
